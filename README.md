# القول الرشيد في أحكام التجويد – Android

## بيانات GitHub المقترحة
- Repository name: `alqawl-alrasheed-tajweed`
- Description: `تطبيق أندرويد لكتاب القول الرشيد في أحكام التجويد، مع قارئ PDF وبحث عربي وفهرس تفاعلي وقاموس مصطلحات.`
- Visibility: Public (أو Private إذا رغبت بإبقاء الشيفرة خاصة)
- Topics: `android`, `tajweed`, `quran`, `arabic`, `islamic-app`, `pdf-reader`

## المزايا
- اسم التطبيق: القول الرشيد في أحكام التجويد
- واجهة عربية RTL بألوان أزرق داكن وذهبي
- قراءة PDF مدمج دون إنترنت
- بحث نصي عربي داخل صفحات الكتاب مع رقم الصفحة ومقتطف
- فهرس موضوعات قابل للنقر
- قاموس مصطلحات مع تعريف وصفحة مرجعية
- حفظ الصفحات المفضلة وآخر صفحة تمت قراءتها
- وضع ليلي
- GitHub Actions لبناء APK تلقائياً

## إنشاء المستودع
1. فك ضغط ملف المشروع.
2. في GitHub اختر New repository.
3. أدخل الاسم أعلاه، واختر Public أو Private، ثم Create repository.
4. ارفع محتويات المجلد كاملة إلى جذر المستودع، بما فيها مجلد `.github`.
5. افتح Actions وشغّل `Build Android APK` أو ادفع commit إلى `main`.
6. بعد نجاح التشغيل نزّل artifact باسم `alqawl-alrasheed-apk` ثم فك ضغطه لتحصل على `app-debug.apk`.

## تنبيه حول المحتوى
البحث يعتمد على النص المستخرج آلياً من ملف PDF؛ قد تؤثر أخطاء OCR/استخراج الحروف في بعض النتائج. القاموس والفهرس قائمة تحريرية أولية مستندة إلى عناوين وتعريفات الكتاب، وينبغي مراجعتها مع النسخة المطبوعة قبل النشر العام.

## متطلبات البناء
JDK 17، Gradle 8.9، Android Gradle Plugin 8.7.3، compileSdk 35.
